ミステリーポットラック Web v6

index.html をブラウザで開いてください。公開時はフォルダ内の全ファイルを同じ構成で配置してください。

編集する場所
- game-data.js：食材名・表記ゆれ・主人公のコメント・各月の導入
- style.css：レイアウト・色・ポップアップ・吹き出し
- app.js：進行、解答判定、保存、ポップアップ
- assets/：PC/SP背景、STEP画像、エンディング画像

エンディングは現在 assets/ending-placeholder.svg という仮画像です。
正式なエンディング画像が完成したら、同名ファイルを差し替えるか、app.js の renderEnding 内のパスを変更してください。

今回の変更
- 食材の正解時：赤い「正解！」＋主人公の吹き出しを閉じられるポップアップで表示。
- 食材名は下の履歴に追加。コメントは「感想を見る」で再確認可能。
- 各月の最後の食材で「今月の鍋の名前を突き止めよ！」も同じポップアップ内に表示。
- 鍋名の正解でも主人公の感想をポップアップ表示。
- ストーリー、操作指示、ミッションの見た目を分けた。
- 「次の内容を表示しました」などの処理報告を削除。
- 4ヶ月目の紙面の文章をWebに重複掲載しない。
- LASTは一つの解答欄で「やみなべ」「やみつきなべ」を判定。後者を先に答えても最終正解。
- エンディングは画像表示方式に変更（画像自体は未制作）。
- ページが自動スクロールする演出はない。

前バージョンと同じ localStorage キーを使用するため、同じブラウザでは進行状態を引き継ぎます。
確認を最初から行いたい場合はページ最下部の「最初からやり直す」を押してください。


v6での変更
- 赤い指示帯とクリック可能な赤ボタンを区別。ボタンには濃い縁・押し込み感・矢印をつけ、押した後はグレーの無効表示にする。
- STEP.0「鍋を準備しました」の一度のクリックで1ヶ月目を解禁。追加の「1ヶ月目へ進む」ボタンを廃止。
- 毎月の内容物確認を赤枠の案内に変更。「謎は開かずに確認」を追記。4ヶ月目の確認も同じ見た目に統一。
- セーブデータは引き継ぎ、旧版でSTEP.0を完了済みの場合は1ヶ月目を自動解禁。
- ストーリー／吹き出しの透過画像化は素材完成後に検討。現時点ではHTMLのまま。
