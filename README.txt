【ヒントの画像素材】
hints.csv はご提供のものをそのまま同梱しています。
CSV内には ./image/*.png を参照する画像が26種類ありますが、
今回は画像ファイル自体が添付されていないため image フォルダは空です。
必要な画像を image フォルダに配置するとヒント内に表示されます。
画像がない間は「画像素材が未配置です」と表示します。
