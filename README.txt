【2026-10-26 更新が表示されない場合の対策】
・index.html の CSS/JS 読み込み先に更新識別子を追加しました。
・公開する際はZIPを展開し、index.html・app.js・style.cssを含む全ファイルを同じ公開フォルダにアップロードしてください。
・ZIP内の mystery-potluck-web-v7 フォルダを丸ごとアップロードして、公開URLが一階層ずれないよう注意してください。
・アップロード後、公開ページの「ページのソースを表示」で potluck-build を検索してください。
  v7-story-debug-cachefix-20261026 が見つかれば新しい index.html が配信されています。
・更新が見えない場合は、サーバー/CDN側のキャッシュ削除、または公開ディレクトリの確認が必要です。
・進行状況は従来どおり保持されます。最初から試す場合は「最初からやり直す」を使用してください。
